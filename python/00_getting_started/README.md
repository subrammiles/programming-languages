# Getting started

## Install
- Download from [python.org](https://www.python.org/downloads/) or use your OS package manager / `pyenv`.
- Check the version: `python3 --version`

## Ways to run Python
| How | Command |
|---|---|
| Run a file | `python3 a_hello_world.py` |
| Interactive shell (REPL) | `python3`, then type code; `exit()` to quit |
| Run a module | `python3 -m json.tool data.json` |
| One line | `python3 -c "print(2 ** 10)"` |

Since **Python 3.13** the REPL has colours, multi-line editing and history.
Type `help(str)` in it to read documentation.
