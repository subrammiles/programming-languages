# What's new in Python

A new Python version is released every **October**, and each is supported for 5 years.

| Version | Released | Highlights | Learn it in |
|---|---|---|---|
| 3.8  | 2019 | walrus `:=`, positional-only `/`, `f"{x=}"` | 02, 06, 03 |
| 3.9  | 2020 | dict `\|` merge, `list[int]` generics, `str.removeprefix`, `zoneinfo` | 05, 15, 03, 18 |
| 3.10 | 2021 | `match`/`case`, `X \| Y` unions, `zip(strict=)`, better errors | 04, 15, `a_python_3_10_and_3_11.py` |
| 3.11 | 2022 | **much faster**, exception groups, `TaskGroup`, `tomllib`, `Self` | 08, 17, 18 |
| 3.12 | 2023 | `def f[T]`, `type` aliases, flexible f-strings, `itertools.batched` | 15, 03, `b_python_3_12.py` |
| 3.13 | 2024 | new REPL, free-threaded build (experimental), `copy.replace`, `@deprecated` | 16, `c_python_3_13.py` |
| 3.14 | 2025 | t-strings, lazy annotations, supported free-threading, subinterpreters, zstd | 03, 15, 16, `d_python_3_14.py` |
| 3.15 | 2026 | `lazy import`, comprehension unpacking, `frozendict`, UTF-8 default | 07, 05, `e_python_3_15.py` |

Check your version with `python3 --version`. Files for newer versions say which version they need at the top.
