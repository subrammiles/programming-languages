# Standard library tour

Python comes "batteries included". A selection of the modules you'll use most:

| File | Modules |
|---|---|
| `a_os_and_sys.py` | `os`, `sys` |
| `b_datetime_and_zoneinfo.py` | `datetime`, `zoneinfo` |
| `c_math_random_statistics.py` | `math`, `random`, `statistics` |
| `d_regex.py` | `re` |
| `e_logging.py` | `logging` |
| `f_argparse.py` | `argparse` (try `--help`) |
| `g_subprocess.py` | `subprocess` |
| `h_hashlib_secrets_uuid.py` | `hashlib`, `secrets`, `hmac`, `uuid` (`uuid7` is 3.14) |
| `i_decimal_and_fractions.py` | `decimal`, `fractions` |
| `j_heapq_and_bisect.py` | `heapq`, `bisect` |
| `k_timeit_and_profiling.py` | `timeit`, `cProfile`, `profiling.sampling` (3.15) |
| `l_text_tools.py` | `textwrap`, `pprint`, `string`, `difflib` |
| `m_compression_and_archives.py` | `zlib`, `gzip`, `compression.zstd` (3.14), `zipfile` |
| `n_sqlite3.py` | `sqlite3` |
| `o_urllib_and_http.py` | `urllib`, `http.server` |
| `p_tomllib_and_configparser.py` | `tomllib`, `configparser` |

Collections, itertools, functools, pathlib, json and csv are covered in their own chapters.
Full list: https://docs.python.org/3/library/
